# 🎭 Party H5 Game — 害你在心口难开·动作版

> 聚会H5互动游戏，微信端秘密任务对抗

## 一句话介绍

每人手持秘密任务，偷偷引导他人做出指定行为，完成后对方接受惩罚、自己得分；你可以随时质疑识破他人的暗算来反杀得分；最终积分垫底的玩家接受团队惩罚。

## 🎮 游戏概览

- **人数**：4-8人
- **场景**：聚会穿插的背景娱乐，不喧宾夺主
- **平台**：微信H5，OpenID绑定身份
- **时长**：自定义（1-2小时或不限时）

### 核心玩法

1. 每人获得3条秘密任务（简单🟢 + 中等🟡 + 困难🔴）
2. 线下偷偷引导目标做出指定行为
3. 完成后声明→目标确认→得分，目标受罚
4. 可以质疑反杀：猜中他人任务→抢分+对方受罚
5. 游戏结束结算，积分最低者接受团队惩罚

### 难度体系

| 难度 | 积分 | 特点 | 库存 |
|------|------|------|------|
| 🟢 简单 | +1 | 聚会中自然发生 | 100条 |
| 🟡 中等 | +2 | 需要引导技巧 | 100条 |
| 🔴 困难 | +3 | 需要演技和套路 | 100条 |
| 💀 超难 | +5 | 极其离谱 | 30条 |

## 🔑 核心机制

- **声明完成** → 目标确认/否认，否认则任务刷新
- **质疑反杀** → 猜中任务内容即抢分，被猜者受罚
- **弃牌换牌** → 随时换同难度新任务
- **动态流** → 实时公开完成的任务和质疑记录
- **匿名爆料** → 模糊提示全场任务，增加警觉
- **勋章系统** → 结算时根据数据颁发趣味勋章
- **六维能力图** → 狼性/鹰眼/戏骨/磁场/铁皮/手气

## 📋 技术要点

- 微信公众号H5，OpenID绑定用户
- 应用内消息确认（不使用微信模板消息推送）
- 后台创建游戏→生成二维码/链接
- 支持预设开始/结束时间
- 全员点击结束或时间到自动结算
