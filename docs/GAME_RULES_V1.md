# 聚会H5游戏 · 完整规则文档 v1

## 一句话定义

**害你在心口难开 · 动作版** —— 每人手持秘密任务，偷偷引导他人做出指定行为，完成后对方接受惩罚、自己得分；你可以随时质疑识破他人的暗算来反杀得分；最终积分垫底的玩家接受团队惩罚。

---

## 一、游戏流程总览

```
后台创建游戏 → 设定人数、时间、团队奖励/惩罚 → 生成二维码/链接
        ↓
玩家扫码进入 → 输入昵称 → 等待人齐
        ↓
人齐后游戏自动开始 / 到达预设开始时间自动开始
        ↓
每位玩家获得3条秘密任务（1🟢简单 + 1🟡中等 + 1🔴困难），每条附带对应难度惩罚
        ↓
  ┌─────────────────── 游戏进行中 ───────────────────┐
  │                                                   │
  │  【执行任务】                                     │
  │  线下偷偷引导目标做出指定行为                      │
  │  完成后点击"声明完成" → 选择目标玩家               │
  │  目标玩家收到确认弹窗 → 确认✅ / 否认❌            │
  │                                                   │
  │  【质疑反杀】                                     │
  │  随时可以点击"质疑"按钮                           │
  │  输入猜测的任务内容 → 指定被质疑的玩家             │
  │  被质疑玩家确认是否猜中 → 选择命中的是哪条任务     │
  │                                                   │
  │  【换牌】                                         │
  │  随时可弃牌，弃牌后刷新同难度新任务                │
  │                                                   │
  │  【动态流】                                       │
  │  实时滚动：完成的任务 + 质疑成功的记录             │
  │  匿名爆料：至少2条，不足自动补足                   │
  │                                                   │
  └───────────────────────────────────────────────────┘
        ↓
游戏结束（全员点结束 / 预设时间到）→ 直接结算
        ↓
公布排名 → 公开未完成任务 → 精彩回放 → 勋章颁发 → 能力图展示 → 惩罚/奖励执行
```

## 二、角色与入口

### 2.1 角色

| 角色 | 说明 |
|------|------|
| **后台** | 创建游戏、设定参数、生成入口 |
| **玩家** | 扫码进入、输入昵称、参与游戏（4-8人） |

### 2.2 玩家进入流程

1. 扫描二维码或点击链接进入H5
2. 首次进入：输入昵称，系统通过微信OpenID绑定唯一身份
3. 再次进入：自动识别OpenID，读取当前游戏进度
4. 等待参与人数达到设定人数 → 游戏开始

### 2.3 中途规则

- 参与人数未满前，随时可以加入
- 不存在退出机制，关闭/离开页面不影响游戏
- 重新打开自动恢复进度

## 三、任务体系

### 3.1 任务结构

每条任务包含：

| 字段 | 说明 |
|------|------|
| 任务内容 | 需要引导目标做出的行为描述 |
| 目标 | 指定1人 / 指定多人 / 任意玩家（不可选自己） |
| 难度 | 🟢简单 / 🟡中等 / 🔴困难 / 💀超难 |
| 积分 | 🟢+1 / 🟡+2 / 🔴+3 / 💀+5 |
| 绑定惩罚 | 同难度随机绑定的惩罚内容 |

### 3.2 难度分级

| 难度 | 积分 | 任务特点 | 惩罚特点 | 库存 |
|------|------|----------|----------|------|
| 🟢 简单 | +1分 | 聚会中自然可能发生 | 轻微、好笑 | 100条 |
| 🟡 中等 | +2分 | 需要一定引导技巧 | 有点尴尬但不难受 | 100条 |
| 🔴 困难 | +3分 | 需要演技和套路，容易被识破 | 比较社死或出力 | 100条 |
| 💀 超难 | +5分 | 极其离谱，几乎不可能不被发现 | 非常社死 | 30条 |

### 3.3 超难任务触发规则

- 💀超难和🔴困难**共用同一个任务栏位**
- 初始手牌仍然是3张（🟢🟡🔴），不会开局就拿到超难
- 🔴困难栏位刷新时（完成/否认/被质疑成功），**20%概率出💀超难，80%出🔴困难**
- 💀超难弃牌 → 刷新回🔴困难（同样20%概率出超难）
- 💀超难完成/被否认/被质疑成功 → 刷新🔴困难（同样20%概率出超难）
- 手牌始终3张，超难和困难永远只占同一个栏位

### 3.4 任务刷新规则

| 事件 | 刷新行为 |
|------|----------|
| 初始进入 | 获得3条任务（1🟢 + 1🟡 + 1🔴） |
| 完成一条（目标确认） | 该条移除，刷新1条同难度新任务（困难栏位20%出超难） |
| 声明完成被否认 | 该条移除，刷新1条同难度新任务（困难栏位20%出超难） |
| 质疑成功（被别人猜中） | 被猜中的任务移除，刷新1条同难度新任务（困难栏位20%出超难） |
| 主动弃牌 | 该条移除，🟢🟡刷新同难度，💀刷新回🔴（困难栏位20%出超难） |

**手牌永远保持3条。**

### 3.5 任务库规则

- 🟢🟡🔴各100条任务 + 100条惩罚，💀30条任务 + 30条惩罚
- 全局共享任务库，不同玩家可以抽到相同任务，允许重复
- 任务与惩罚的绑定：**同难度随机绑定**，非固定配对
- 每次刷新重新随机配对

### 3.6 任务类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 言语诱导 | 引导目标说出特定内容 | "让目标夸你今天好看" |
| 行为引导 | 引导目标做出特定动作 | "让目标主动跟你碰杯" |
| 情感操控 | 利用社交压力让目标就范 | "让目标当众向你道歉" |
| 反向操作 | 需要先做某事再引导 | "先给目标倒酒，让目标回敬你" |

## 四、核心机制

### 4.1 声明完成

```
玩家A线下成功引导目标做出指定行为
  → 点击任务卡上的"声明完成"按钮
  → 选择目标玩家（"任意玩家"类型此时也要指定具体是谁，不可选自己）
  → 目标玩家B收到确认弹窗
```

**确认弹窗内容**：
- 发起方昵称
- 任务内容
- 惩罚内容
- **不显示任务难度等级**
- 操作：✅ 确认 / ❌ 否认

| 结果 | 效果 |
|------|------|
| ✅ 目标确认 | A获得积分，B接受惩罚，该任务移除并刷新，动态流公开 |
| ❌ 目标否认 | 任务不算完成，该条任务移除并刷新新任务，无额外惩罚 |

**规则**：
- 每条任务只能声明一次，否认后不可重试
- 可以同时声明多条任务完成，逐条独立确认
- 每条任务可声明多个目标（如果任务指定了多人）

### 4.2 质疑反杀

```
玩家B感觉某人在害自己（或观察到了线索）
  → 点击"质疑"按钮
  → 输入猜测的任务内容（如"让我跟他碰杯"）
  → 指定被质疑的玩家A（不可选自己）
  → A收到弹窗
```

**质疑确认弹窗内容**：
- 质疑方昵称
- 猜测的任务内容
- 操作：
  - ✅ 猜中了 → 选择被猜中的是哪一条任务
  - ❌ 没猜中

| 结果 | 效果 |
|------|------|
| 确认猜中 | B获得该任务积分，A接受该任务惩罚，该任务从A列表移除并刷新，动态流公开 |
| 否认 | 无事发生，A的任务不变，B无惩罚 |

**规则**：
- **随时可以发起质疑**，不需要等对方声明完成
- 是否猜中由被质疑的人判断，确认时需选择命中的具体任务条目
- 需要精确匹配，由被猜者自行判断"这个描述和我的任务是不是同一件事"
- 否认后不刷新任务，被质疑的人任务保持不变
- 被质疑的人即使撒谎否认，线下社交环境会形成自然压力

### 4.3 弃牌换牌

- 随时可以点击任务卡上的"换牌"按钮
- 🟢🟡弃牌后刷新同难度新任务
- 💀弃牌后刷新回🔴困难（20%概率出超难）
- 无冷却、无次数限制

### 5.2 任务卡展示规范

| 元素 | 展示方式 |
|------|----------|
| 难度 | 卡片左边色条：🟢🟡🔴💀 |
| 积分 | 卡片右上角小标 "+1"/"+2"/"+3"/"+5" |
| 任务内容 | 主文字，最大 |
| 目标 | "→ 小红" 或 "→ 任意" |
| 惩罚 | 次要文字，小一号 |

### 5.3 积分展示

| 信息 | 可见范围 |
|------|----------|
| 自己的积分 | 仅自己可见 |
| 是否处于后2名 | 仅后2名的玩家可见警告提示 |
| 具体排名 | 结算时公布 |
| 他人积分 | 不可见 |

### 5.4 动态流

**推送时机**：
- 任务声明完成且目标确认后
- 质疑成功后

**展示内容**：

| 信息 | 是否展示 |
|------|----------|
| 发起方昵称 | ✅ |
| 目标玩家昵称 | ✅ |
| 任务内容 | ✅ |
| 惩罚内容 | ✅ |
| 任务难度 | ❌ 不展示 |
| 任务积分 | ❌ 不展示 |

### 5.5 匿名爆料

**生成规则**：
- 每次有人完成任务时，从全场玩家的当前任务池中随机取2条生成匿名爆料
- 匿名爆料区**至少保持2条**，不足时自动补足
- 开局时即生成2条初始爆料

**内容规则**：
- 模糊化处理，不指明具体玩家和具体动作
- 超难任务的爆料可更"诱人"，如"💡 有人拿到了一个值5分的危险任务……"

**消失规则**：
- 对应任务被刷新/完成后，该条匿名爆料消失
- 消失后自动补足至2条

**示例**：
- "💡 有人想让三位玩家做同一件事…"
- "💡 有人正在试图让你做一件很过分的事，小心哦~"
- "💡 刚才那个碰杯，可能没你想的那么简单…"
- "💡 有人手上的任务已经剩最后一条了…"
- "💡 有人拿到了一个值5分的危险任务……"

## 六、确认/弹窗机制

### 6.1 消息到达方式

- 应用内消息列表，玩家主动点击弹出确认弹窗
- 不使用微信模板消息推送
- 页面轮询检查新消息

### 6.2 确认弹窗类型

| 类型 | 展示内容 | 操作 |
|------|----------|------|
| 声明完成确认 | 发起方昵称 + 任务内容 + 惩罚内容 | ✅ 确认 / ❌ 否认 |
| 质疑确认 | 质疑方昵称 + 猜测的任务内容 | ✅ 猜中了（选择哪条） / ❌ 没猜中 |

## 七、游戏结束与结算

### 7.1 结束条件

| 条件 | 触发方式 |
|------|----------|
| 全员点击结束 | 所有玩家都点了"结束游戏" |
| 预设时间到 | 创建游戏时设定的结束时间，到点直接结算 |

时间到时，未确认的任务全部作废，直接结算。

### 7.2 结算页面

**第一步：排名公布**
- 从高到低展示全员排名
- 首次公开具体积分和难度分布
- 最低分玩家高亮标记（并列则全部标记）

**第二步：未完成任务公开**
- 逐个展示每个玩家手上未完成的任务
- "原来小明还想让小红亲他一口！"

**第三步：精彩回放**
- 按时间轴展示动态流所有记录
- 包含质疑成功的反杀记录

**第四步：勋章颁发**
- 根据游戏数据颁发对应勋章（详见第八节）

**第五步：能力图展示**
- 六维雷达图 + 趣味解释（详见第九节）

**第六步：执行惩罚与奖励**
- 最低分玩家接受团队惩罚（线下执行）
- 全员获得团队奖励

### 7.3 团队惩罚与奖励

- 后台预设，可设置多个
- 纯展示，线下自觉执行
- 无轻重次序，全员共同

## 八、勋章系统

结算时根据游戏数据自动颁发，可叠加，一人可拿多枚，并列都发。

| 勋章 | 获得条件 | 介绍 |
|------|----------|------|
| 🎭 戏精勋章 | 成功完成最多任务 | 天生演员，每个眼神都是戏，你身边的朋友没有一个是安全的 |
| 🛡️ 测谎勋章 | 质疑成功次数最多 | 你的雷达永远在线，谁想害你一眼看穿，朋友圈里最不能惹的人 |
| 🐟 猎物勋章 | 被完成任务次数最多 | 全场最单纯的存在，别人让你干嘛你就干嘛，鱼的记忆，神的信任 |
| 💀 社死勋章 | 接受惩罚次数最多 | 你为这场聚会付出了太多，社死的尽头是重生，下次还敢 |
| 🤫 潜伏勋章 | 完成任务最少但质疑成功最多 | 不怎么出手，但谁也别想骗你，聚会的暗影观察者 |
| 🍀 天命勋章 | 获得超难任务次数最多 | 命运总给你最离谱的牌，但你还活着，这就是奇迹 |

## 九、六维能力图

结算页展示六边形雷达图（0-100分），每维度附带趣味解释。

| 维度 | 计算依据 | 趣味解释 |
|------|----------|----------|
| ⚔️ 狼性 | 成功完成任务数 | 你有多能套路朋友——狼性越高，越不适合做朋友 |
| 👁️ 鹰眼 | 质疑成功次数 | 你有多能看穿套路——鹰眼越高，越没人敢在你面前演戏 |
| 🎭 戏骨 | 任务被质疑失败的次数越低分越高 | 你骗人的时候有多自然——戏骨越高，越适合去拿奥斯卡 |
| 🧲 磁场 | 被指定为目标的次数 | 你有多容易成为目标——磁场越高，说明你人缘好（或者好骗） |
| 🛡️ 铁皮 | 接受惩罚次数越少分越高 | 你有多能躲过惩罚——铁皮越高，越像一条滑溜的泥鳅 |
| 🎰 手气 | 手上出现过超难任务的比例 | 你的命有多离谱——手气越低说明老天还爱你，手气越高说明老天在考验你 |

## 十、防作弊与社交博弈设计

| 机制 | 防什么 | 怎么起作用 |
|------|--------|-----------|
| 确认时展示惩罚 | 防目标无脑配合 | 目标知道认了就要受罚，有动机否认 |
| 积分隐藏+后2名警告 | 防摆烂 | 不知道差距，不敢放松；但知道自己危险会加把劲 |
| 难度隐藏 | 防按价值配合 | 不知道配合的是1分还是5分任务 |
| 每条任务只能声明一次 | 防反复试探 | 否认=该任务作废 |
| 质疑反杀机制 | 防串谋+增加主动性 | 随时可能被识破，做任务要更隐蔽 |
| 动态流公开 | 防耍赖+增加社交压力 | 全员可见"谁害了谁" |
| 匿名爆料 | 增加警惕性 | 不时收到模糊提示，让人更警觉 |
| 未完成任务公开 | 防划水 | 游戏结束时剩一堆任务会很社死 |
| 不可选自己为目标 | 防刷分 | 不能自己配合自己 |

## 十一、后台配置项

| 配置 | 说明 | 示例 |
|------|------|------|
| 参与人数 | 4-8人 | 6人 |
| 开始时间 | 可选，到时间自动开始 | 2026-06-07 19:00 |
| 结束时间 | 到时间自动结算 | 2026-06-07 22:00 |
| 团队奖励 | 可设置多个，纯展示 | 海马体四人闺蜜套餐 |
| 团队惩罚 | 可设置多个，纯展示 | 合唱一首歌 / 真心话大冒险 |
